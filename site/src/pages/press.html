Short description

{{appName}} is a number puzzle with one twist: gravity. Tap a number, tap a column, and it falls to the lowest empty cell. Fill the grid so every row, column and box holds each number once, before the clock runs out. Because numbers fall, the order of your moves is the puzzle.

Features

  • 230 levels on three boards: Quick 4×4 (30), Classic 6×6 (100) and Master 9×9 (100), all open from the start
  • A Daily Drop puzzle that is the same for everyone, with streaks
  • Every level can be solved by logic alone, with no guessing
  • Game Center achievements and leaderboards, iCloud sync between iPhone and iPad
  • Original rules, art, sound and levels
