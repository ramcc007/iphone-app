2. PURPOSE AND AUDIENCE
NumFall is a single-player number puzzle with gravity, for anyone aged 4+ who enjoys short logic puzzles. The player taps a number, then a column, and the number falls to the lowest empty cell. The goal is to fill the grid so every row, column and box holds each number once, before the timer runs out. Because numbers fall, the order of the drops is part of the puzzle. Value: a quick, relaxing brain workout with three board sizes (4x4, 6x6, 9x9), 230 levels that can all be solved by logic alone, and a new Daily Drop puzzle every day.

3. SETUP AND HOW TO USE IT
No login, account or sample files are needed. On first launch, type any name (for example "Alex") and tap "Let's play". A short tutorial teaches the move. From the home screen, pick a board (Quick, Classic or Master) and tap the Play button, or open the Daily Drop card. All three boards are open from the start.

4. EXTERNAL SERVICES
The app uses no third-party services, SDKs, servers, analytics, advertising, payment processors or AI services. It uses only Apple frameworks:
- Apple Game Center (GameKit): optional achievements and leaderboards. The game works fully without signing in.
- Apple iCloud key-value storage: syncs the player's own progress across their devices. The developer receives none of it.
- Local notifications (UserNotifications): an optional daily reminder, off until the player turns it on. Nothing is sent from a server.
The website numfall.store only hosts the Privacy Policy, Terms of Use and Support pages.

5. REGIONAL DIFFERENCES
None. The app works the same in every region where it is offered. The text is in English. The Daily Drop puzzle changes at midnight in the player's local time.

6. REGULATED INDUSTRY OR THIRD-PARTY MATERIAL
Not applicable. NumFall is a casual puzzle game and is not in a regulated industry. All levels, artwork, sounds and code are original; the only font is licensed under the SIL Open Font License.

## How to make the recording (iPhone, about 3 minutes)
1. Install build 1.0 (8) from the TestFlight app. If NumFall is already installed, delete it first so the name screen appears.
2. Settings → Control Center → add Screen Recording (once).
3. Swipe down from the top-right corner → tap the record button (grey circle) → wait for the 3-second countdown.
4. Swipe back to the Home Screen and tap NumFall (the recording must start with launching the app).
5. Type a name → Let's play → play the three tutorial levels.
6. On the home screen show the three boards → play Quick level 1: make one wrong drop (a heart is lost), tap Undo, tap Hint, finish the level.
7. Back home → open Daily Drop briefly → back.
8. Open Settings (top-right icon): show Privacy Policy, Terms, Support, the reminder switch, and Reset all progress (no need to confirm).
9. Stop: tap the red status pill at the top → Stop. The video is saved in Photos.
10. If the file is too big to attach, trim it in Photos, or upload it to Google Drive / iCloud Drive and paste a "anyone with the link" share link in the reply.
