# NumFall YouTube channel and Shorts kit

Files (GitHub → branch claude/happy-ride-mm490y → design/marketing):
- Banner: `youtube-banner-2560x1440.png` (text inside YouTube's safe area for phones)
- Profile picture: `site/src/static/press-icon-1024.png`
- Videos: `short-*.mp4` (1080x1920, voice + music)
- Covers / thumbnails: `covers/cover-*.jpg` (1080x1920)

## 1. Set up the channel (once, on a computer)
1. youtube.com → sign in → profile picture → **Create a channel** → name **NumFall** → handle **@numfallgame**.
2. **studio.youtube.com → Customization**:
   - **Branding**: Picture = the icon; Banner image = the banner.
   - **Basic info → Description**:
     ```
     NumFall is a number puzzle with gravity for iPhone and iPad. Tap a number, tap a column, and watch it fall to the lowest gap. Fill the grid so every row, column and box holds each number once, before the clock runs out.

     New puzzle shorts every day: clutch finishes, "guess the number" challenges and the most satisfying drops.

     Search "NumFall" on the App Store (iPhone and iPad only). No ads.
     ```
   - **Links** → Add link: Title `Get NumFall (iPhone & iPad)` → URL `https://apps.apple.com/app/apple-store/id6820579220?pt=129582636&mt=8&ct=youtube`. Add a second: `Website` → `https://www.numfall.store`.
   - **Contact info**: support@numfall.store.
3. **Settings → Channel → Basic info**: Country = India. Keywords: `NumFall, puzzle game, number puzzle, brain games, logic puzzles, iPhone games, iOS games, mobile games, indie game`.
4. **Settings → Upload defaults**: Category **Gaming**, comments **Allow all**.

## 2. Upload a Short (phone, YouTube app)
1. **+** → **Short** → **Add** (bottom left, gallery) → choose the video → **Next** (keep the full length) → **Next**.
2. Fill in **Caption/Title**, then **Settings**:
   - **Select audience**: **No, it's not made for kids** (it's for everyone; "made for kids" turns off comments).
   - **Altered or synthetic content**: **Yes** for the five voiced videos (the voice-over is AI-generated). Honest labelling avoids penalties and does not hurt reach much.
   - **Visibility**: Public. **Allow remixing**: on.
3. Thumbnail: tap the **pencil on the thumbnail**. If you can upload an image, use the matching `cover-*.jpg`; otherwise pick the frame at the time given below.
4. **Upload Short**. Then open studio.youtube.com on a computer → **Content → Shorts** → the video → paste the full **Description** and **Tags** below → **Save**.
5. Pin your first comment (tap ⋮ on your comment → **Pin**).

Post one a day, in the order below. Best times for a US + UK audience: **6:30-8:30 AM India time** (US evening) or **9:30-11:30 PM India time** (UK evening).
