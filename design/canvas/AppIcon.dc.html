At small sizes the three tiles still read as "a block landing on a stack". iOS drops fine detail automatically when the icon is built as layers.
How it gets built
• One 1024 × 1024 master. Xcode generates every iPhone, iPad and Mac size from it.
• Made as separate layers (background, tiles, digits) in Apple's Icon Composer, so iOS 26 can render the glass, dark, clear and tinted looks.
• Vector shapes and the Fredoka font (free open licence), so no blurry edges at any size.
