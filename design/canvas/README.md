# Design canvas source

Snapshot of the "Dropku – Game Screens" design canvas (claude.ai artifact). Each `*.dc.html` file is one screen; `canvas.json` is the layout.
Screens 3 (Demo), 4 (Tutorial) and 7 (Game) contain working prototype logic that the fail-safe tests in `tools/failsafe/` run against.
The live canvas is the source of truth for visuals; refresh this snapshot when it changes.
