# Design canvas source

Snapshot of the "NumFall – Game Screens" design canvas (claude.ai artifact). Each `*.dc.html` file is one screen; `canvas.json` is the layout.
Screens 3 (Demo), 4 (Tutorial), 7 (Game) and 15 (iPadGame) contain working prototype logic that the fail-safe tests in `tools/failsafe/` run against.
The live canvas is the source of truth for visuals; refresh this snapshot when it changes.
